聚合搜索与热门推荐

全网聚合搜索已升级为搜索工作台，支持快捷关键词、今日热门推荐、结果订阅与一键搜盘。

三网盘转存与管理

支持夸克、阿里云盘、115 网盘授权接入，转存、目录浏览、文件管理和保存路径配置统一在系统内完成。

内置 AList 网盘层

内置 AList 负责网盘挂载、签名直链和高性能流式读取。旧的内置 WebDAV 服务已移除，代码路径更清爽。

播放代理优化

夸克播放优先走 AList 签名地址，阿里云盘支持预览转码入口，115 保持 Range 友好的直连代理。

STRM 生成与记录缓存

内置节点通过 AList API 扫描，不再依赖 8088 WebDAV。生成记录按节点拆分展示，支持增量扫描和域名替换。

容器化部署

Docker 镜像自动安装 Linux 版 AList，默认暴露 8000 与 5244，数据目录可通过 volume 持久化。

当前架构说明

系统内部已从“内置 WebDAV”切换为“内置 AList + 播放代理”。外部 WebDAV 仍可作为用户自定义来源保留。

最近更新

这些是当前本地版本已经完成的重点变化。

  • 移除内置 WebDAV：删除旧服务代码与 wsgidav 依赖，内部节点统一使用 AList。
  • 夸克播放修复：STRM 改用 `/play/quark_preview`，最终跳转到 AList 签名播放地址。
  • 阿里云盘增强：支持移动端 Refresh Token 扫码获取、转存与预览播放入口。
  • 115 网盘接入：支持扫码授权、内置挂载、STRM 生成与只读文件管理。
  • Docker 适配：镜像内自动下载 AList Linux 二进制，Compose 配置已清理 8088 端口。
  • 界面优化：菜单图标补齐，全网聚合搜索升级为带热门推荐的工作台页面。
